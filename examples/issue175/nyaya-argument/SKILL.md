# Nyāya five-membered argument

Write the argument in Russian. Use exactly five sections, in this order, with
this heading format: number, Russian name, Sanskrit transliteration in
parentheses, then a dash and the section's role.

### 1. Пратигья (Pratijñā) — Тезис
State the thesis: the claim about the subject (pakṣa) to be proved.

### 2. Хету (Hetu) — Причина
Give the reason: the property of the subject that proves the thesis.

### 3. Удахарана (Udāharaṇa) — Пример
Give the general rule together with a familiar example where it holds
(e.g. "wherever there is smoke there is fire, as in a kitchen").

### 4. Упанайя (Upanaya) — Применение
Apply the rule to the subject: show the subject has the reason.

### 5. Нигамана (Nigamana) — Заключение
Restate the thesis as proved.

## Rules
- Keep all five members, even when an answer must be short.
- Cite at least one source for the rule in Udāharaṇa (a text, a commentator, or a standard example).
- If the argument has a known fallacy (hetvābhāsa), name it after the five members.
